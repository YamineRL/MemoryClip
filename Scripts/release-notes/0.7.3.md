## What's new

- **Detected appointments ask before writing.** A clip that looks like an
  event now offers it instead of saving — Add creates it, Edit… opens a
  draft in Calendar for tweaking first, Not Now leaves it alone. Tapping
  the offer banner raises the same three choices as a dialog.
- **The "Added to your calendar" banner opens the event's day.** Tapping
  it — or its Open button — lands Calendar on the date the event landed
  on, and Undo still retracts the creation it announced.
- Clipboard reliability hardening: an edit made while OCR, translation,
  thumbnail or note work is still in flight can no longer be overwritten
  by the stale write-back, and the local store migration survives a
  permissions hiccup without losing history.
- The release bundle builds on the current Swift toolchain again.
