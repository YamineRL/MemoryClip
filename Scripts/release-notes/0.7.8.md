### New

- **Command palette**: `⌘K` (or `:` in vim mode) lists every action the
  selected clip offers, with the key that does it directly. Return pastes
  the result, `⌘Return` replaces the clip (`⌘Z` undoes it), `⌥Return`
  copies and keeps the panel open. Actions you run most rise to the top.
- The right-click **Transform** menu now lists only transforms that would
  change the clip.

### Fixes

- **Settings**, the tour and **Permissions** now always open where you can
  see them: unminimised, on the current Space and screen, and in front of
  full-screen apps.
- **Translation**: if the target language is not downloaded, Settings now
  says so and offers the download, instead of the preview staying silent.
- **Clean links**: Instagram post links lose their `psln` share ID.
