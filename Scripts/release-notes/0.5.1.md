## What's new

- **The window that opens after an update now offers to tell you about the next
  one.** macOS drops an ad-hoc signed app's permissions every time it is
  replaced, so MemoryClip already opens a window after an update to ask for them
  back — which means it opens for exactly the people who installed by hand. The
  daily update check is offered there too, still off by default and still
  something that never installs anything itself.
