### Calendar

- The panel's **Add to calendar** button now honours the suggestions
  setting: while event suggestions are on, pressing it (or the `c` key)
  opens the same **Add / Edit… / Not Now** review the suggestion banner
  offers — you see the title, day and place MemoryClip detected before
  anything is written.
- Every manual add now posts the **created-event notification** carrying
  **Open in Calendar** — which lands on the event's own day — and
  **Undo**, so "added" is never something you have to take on faith.
- Detection understands labelled invitation layouts: a clock time on its
  own `TIME:` row is now joined to the date instead of producing an
  all-day event, and section headers like "EVENT DETAILS" or bare
  `DATE:` labels can no longer become the event's title.
- Offer and confirmation banners now show the detected **location**, so a
  wrong venue is visible before and after the event is added.

### Build hardening

- `Scripts/verify_app.sh` fails the app build if a module resource
  bundle the code needs is missing from the package — the class of bug
  that crashed the Shortcuts settings pane.
- `publish_release.sh` now ends a release on its notes commit rather
  than on the Homebrew cask bump, and refuses a release whose notes file
  is missing or already committed.
