### Notifications

- Problems that used to fail silently now show a notification saying what happened and what to do. Clicking it opens the right setting.
  - Clip not translated: language not downloaded
  - Note not saved
  - Apple Intelligence is off
  - Image too large to keep
  - Screenshot folder unreachable
  - Secret not saved
  - History not saved
  - Panel opened without Touch ID
  - Calendar add or undo failed
  - Update download failed
- Each notification shows at most once per run.

### Pinboards

- Clicking **+** or **Rename Pinboard…** puts the cursor in the name field.
- The pinboard row scrolls to the new name field.
- A name already taken, or longer than 40 characters, now gets a message instead of nothing.

### Translation and notes

- Short text in any non-Latin script is translated.
- Note titles name the subject and the kind of text.

### Settings and panel

- Row icons are plain symbols.
- Shortcut descriptions line up in one column.
- Rows that depend on a switch ease in, and grey out as soon as it is off.
- Panel motion is quicker.
